## Tech Stack

- **Framework**: React 18
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS 3
- **Icons**: Lucide React
- **Mapping**: Leaflet + CartoDB clean architectural tiles
- **Deployment**: Vercel-ready with `vercel.json`

## Development & Build

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Local Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
```
Output files will be generated in the `dist` directory.

### Preview Production Build
```bash
npm run preview
```

## Vercel Deployment

1. Import the repository in [Vercel](https://vercel.com).
2. Configure settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. Click **Deploy**.
